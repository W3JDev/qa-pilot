How it works

One command. Five agents. One report.

Manual QA after every deploy is the silent tax on every product team. QA Pilot eliminates it.

1

Point it at a URL

Run qa-pilot run cockpit.yaml or call the API. Give it a URL — or a YAML with user journeys and viewports.

2

Agents run in parallel

QA Lead dispatches all five agents simultaneously. Each drives a real Chromium browser, guided by an LLM that picks the next action from what it sees on screen.

3

Get a unified report

Typed Findings aggregated into a single Markdown or JSON report. Posted to GitHub PR comments, Slack, Telegram, or written to a file.

The team

Five specialists. One mission.

Each agent owns a distinct slice of quality — together they cover what no single tool can.

Vega

Smoke Agent

🔥

"Does the app respond at all?"

HTTP status checks, render verification, basic responsiveness. The first signal that something is broken — or not.

Output: Pass / fail per URL with HTTP + render check

Iris

Visual Agent

👁

"What does it look like at every viewport?"

Screenshots vs baselines across desktop, tablet, mobile. Pixel diffs. Broken image detection. Layout regressions.

Output: Screenshots, pixel diffs, broken-image flags

Kai

Journey Agent

🧭

"Can a user actually do the thing?"

Scripted user journeys with click, type, scroll, assert steps. Each step reported with pass/fail and reproduction steps.

Output: Per-step pass/fail with full repro steps

Argus

Watchdog Agent

🐺

"What's exploding in console / network?"

Captures every console error, stack trace, and failed network request. Severity-scaled: 5xx blocker → console warning low.

Output: Bug list with stack traces and failed requests

Sage

Aesthetic Agent

✦

"Does this feel premium or AI-built?"

Polish and perceived quality. Ranks issues by visual impact. The agent that catches what automated tests never notice.

Output: Punch list of polish items, ranked by visibility

QA Lead

The orchestrator that dispatches all five agents in parallel and aggregates their Findings into a single typed report.
